Геометрия¶

Меши представляют геометрические данные в Thunder Engine. Система мешей обеспечивает загрузку, рендеринг и оптимизацию 3D-геометрии для статических и анимированных объектов.

Обзор¶

Меш является основным строительным блоком для всех видимых объектов в сцене. Система поддерживает:

  • Статические меши — для зданий, ландшафтов, реквизита

  • Скелетные меши — для персонажей и анимированных объектов

  • Процедурные меши — геометрия, генерируемая во время выполнения

  • Оптимизации — LOD, пакетная обработка, инстансный рендеринг

  • Форматы файлов — OBJ, FBX, GLTF

Ресурс меша

Ресурс, содержащий данные вершин и индексов. Загружается из файлов OBJ, FBX или GLTF.

MeshRenderer

Компонент для рендеринга статических мешей. Поддерживает материалы, тени и отсечение.

SkinnedMeshRender

Компонент для рендеринга скелетных мешей с анимацией.

Типы мешей¶

Статический меш

Геометрия, которая не изменяется во время игрового процесса. Оптимизирована для статических объектов:

  • Здания, ландшафты, реквизит

  • Поддерживает статическую пакетную обработку

  • Более высокая производительность

Скелетный меш

Геометрия, которая деформируется под воздействием скелетной анимации:

  • Персонажи, животные, анимированные объекты

  • Содержит данные о весах вершин (веса костей)

  • Обновляется на GPU для производительности

Динамический меш

Геометрия, генерируемая во время выполнения:

  • Террейн, вода, процедурные объекты

  • Может динамически обновляться

  • Требует ручного управления буферами

Форматы файлов¶

Thunder Engine поддерживает следующие форматы 3D-моделей:

Формат

Особенности

OBJ

Простой текстовый формат. Подходит для статической геометрии. Не поддерживает анимацию или скелеты.

FBX

Индустриальный стандарт. Поддерживает анимацию, скелеты, морфинг, камеры, источники света. Рекомендуется для сложных ресурсов.

GLTF/GLB

Современный формат для приложений реального времени. Эффективная загрузка, поддержка PBR, анимации.

При импорте ресурсов все данные будут преобразованы во внутренние форматы Thunder Engine:

  • Вся геометрия будет преобразована в ресурсы Mesh

  • Анимация будет преобразована в AnimationClip

  • Ресурсы материалов также будут созданы (в настоящее время недоступно)

Все ресурсы могут использоваться независимо друг от друга в ваших проектах.

Настройки импорта¶

При импорте 3D-модели доступны следующие настройки:

Use Custom Scale (bool)

Включает использование пользовательского масштаба при импорте.

  • true — использовать значение из поля Custom Scale

  • false — использовать исходный масштаб модели

По умолчанию: false.

Custom Scale (float)

Масштаб модели при импорте. Применяется только если Use Custom Scale = true.

  • Диапазон: от 0.001 до 1000.0

  • По умолчанию: 1.0

Совет

Используйте для преобразования единиц измерения (например, из сантиметров в метры: 0.01).

Import Color (bool)

Импортировать цвета вершин из модели.

  • true — цвета вершин будут загружены и доступны в шейдерах

  • false — цвета вершин игнорируются

По умолчанию: true.

Import Normals (bool)

Импортировать нормали из модели.

  • true — нормали загружаются из файла

  • false — нормали не импортируются (могут быть сгенерированы позже)

По умолчанию: true.

Примечание

Нормали необходимы для корректного освещения. Если в модели отсутствуют нормали, рекомендуется включить их генерацию.

Import Animation (bool)

Импортировать анимационные данные из модели.

  • true — анимации будут извлечены и сохранены как AnimationClip

  • false — анимации игнорируются (только статическая геометрия)

По умолчанию: true.

Compress Animation (enum)

Метод сжатия анимационных данных.

Доступные значения:

  • None — без сжатия, максимальная точность

  • KeyframeReduction — удаляет избыточные ключевые кадры

  • CurveOptimization — оптимизирует кривые с указанной точностью

По умолчанию: KeyframeReduction.

Совет

Используйте сжатие для уменьшения размера анимационных файлов. Для фоновых персонажей можно использовать более агрессивное сжатие.

Position Error (float)

Максимально допустимая ошибка позиции при сжатии анимации (в мировых единицах).

  • Меньшее значение = выше точность, больше размер файла

  • Большее значение = ниже точность, меньше размер файла

Диапазон: от 0.0001 до 1.0. По умолчанию: 0.001.

Rotation Error (float)

Максимально допустимая ошибка поворота при сжатии анимации (в градусах).

  • Меньшее значение = выше точность, больше размер файла

  • Большее значение = ниже точность, меньше размер файла

Диапазон: от 0.001 до 10.0. По умолчанию: 0.5.

Scale Error (float)

Максимально допустимая ошибка масштаба при сжатии анимации.

  • Меньшее значение = выше точность, больше размер файла

  • Большее значение = ниже точность, меньше размер файла

Диапазон: от 0.0001 до 1.0. По умолчанию: 0.001.

Рекомендации по оптимизации¶

Для мобильных платформ

  • Используйте меши с < 10 000 треугольников

  • Ограничьте количество костей скелета до 32-64 на персонажа

  • Включите LOD для всех удалённых объектов

  • Используйте сжатие анимации с большими значениями ошибок

  • Предпочитайте статическую пакетную обработку динамической

Для настольных платформ

  • Меши до 100 000 треугольников приемлемы

  • До 256 костей на скелет

  • Используйте occlusion culling для сложных сцен (недоступно в текущей версии)

  • Инстансный рендеринг для повторяющихся объектов

  • Меньшие значения ошибок сжатия анимации

Общие рекомендации

  • Минимизируйте количество материалов на меш

  • Используйте текстурные атласы для уменьшения переключения материалов

  • Группируйте статическую геометрию

  • Регулярно профилируйте количество draw call’ов

  • Используйте LOD для всех объектов на расстоянии > 50

  • Для анимаций используйте сжатие KeyframeReduction с умеренными значениями ошибок

Типичные проблемы и решения¶

Меш не рендерится

  • Убедитесь, что меш загружен (mesh != nullptr)

  • Проверьте, назначен ли материал

  • Убедитесь, что камера смотрит на объект

  • Проверьте ближнюю/дальнюю плоскости камеры

Низкая производительность с большим количеством мешей

  • Включите статическую пакетную обработку для статической геометрии

  • Используйте инстансный рендеринг для повторяющихся объектов

  • Уменьшите количество материалов

  • Включите LOD

  • Используйте occlusion culling

Проблемы с нормалями

  • Убедитесь, что Import Normals включён

  • Убедитесь, что нормали не нулевые

  • Для плавного затенения используйте усреднение нормалей

Анимации воспроизводятся некорректно

  • Убедитесь, что Import Animation включён

  • Убедитесь, что значения ошибок сжатия не слишком высоки

  • Попробуйте отключить сжатие (Compress Animation = None) для тестирования

  • Проверьте, соответствует ли скелет мешу

Размер анимационного файла слишком велик

  • Увеличьте значения Position Error, Rotation Error, Scale Error

  • Используйте более агрессивный метод сжатия (CurveOptimization)

  • Удалите неиспользуемые анимационные каналы

  • Убедитесь, что анимация не содержит избыточных ключевых кадров
