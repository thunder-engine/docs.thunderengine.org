Локализация документации¶

Документация Thunder Engine поддерживает несколько языков. В настоящее время основным языком является английский, но мы приветствуем переводы на другие языки. Локализация реализована с использованием системы gettext, которая позволяет поддерживать переводы без дублирования исходных RST-файлов.

Совет

Если вы хотите перевести документацию на ваш язык, свяжитесь с командой Thunder Engine через GitHub Issues, чтобы скоординировать усилия.

Как работает локализация¶

Система локализации основана на gettext — стандартном инструменте интернационализации:

  1. Исходная документация написана на английском в файлах .rst

  2. Строки для перевода извлекаются из исходных файлов в файлы .pot (шаблоны)

  3. Для каждого языка создаются файлы .po, содержащие переводы

  4. Во время сборки Sphinx использует файлы .po для генерации документации на целевом языке

Преимущества этого подхода:

  • Отсутствие дублирования RST-файлов для каждого языка

  • Изменения в исходной документации легко отслеживать

  • Переводы хранятся отдельно и могут обновляться независимо

Структура проекта¶

thunder-doc/
├── _build/              # generated HTML
├── source/              # original documentation (en)
│   ├── conf.py
│   ├── index.rst
│   └── ...
├── locales/             # folder for translation files
│   └── ru/LC_MESSAGES/
└── make.bat

Добавление нового языка¶

Предположим, вы хотите добавить перевод на русский язык (код языка ru).

Шаг 1: Установите необходимые инструменты

pip install sphinx sphinx-intl gettext

Шаг 2: Создайте шаблоны перевода

Создайте шаблоны .pot из исходных RST-файлов:

# Generate translation templates
make gettext

Шаг 3: Создайте файлы перевода для нового языка

# Create .po files for Russian
sphinx-intl update -l ru

Эта команда создаёт структуру:

locales/
└── ru/
    └── LC_MESSAGES/
        ├── basics.po
        ├── rendering.po
        ├── components.po
        └── ...

Шаг 4: Настройте сборку для нового языка

Отредактируйте Makefile, чтобы добавить цель для нового языка:

# Makefile

# Build English version
html-en:
    sphinx-build -b html source/ _build/html/en -D language=en

# Build Russian version
html-ru:
    sphinx-build -b html source/ _build/html/ru -D language=ru

# Build all versions
html-all: html-en html-ru html-zh

Шаг 5: Настройте Sphinx

Убедитесь, что conf.py настроен для языков:

# conf.py

# Available languages
language = 'en'  # Default

# Directory with translations
locale_dirs = ['locales/']

# Disable compaction for proper link handling
gettext_compact = False

Процесс перевода¶

Редактирование .po файлов

.po файлы имеют следующий формат:

#: ../../basics/getting-started.rst:10
msgid "Getting Started"
msgstr "Начало работы"

#: ../../basics/getting-started.rst:12
msgid ""
"Thunder Engine is a powerful game engine designed for modern game development."
msgstr ""
"Thunder Engine — это мощный игровой движок, разработанный для современной "
"разработки игр."

Где: * msgid — исходная строка на английском * msgstr — перевод на целевой язык (изначально пуст)

Что нужно переводить

  • ✅ Весь текстовый контент (заголовки, абзацы, списки)

  • ✅ Описания свойств и методов

  • ✅ Комментарии в примерах кода

  • ✅ Предупреждения и примечания (.. note::, .. tip::)

  • ❌ Имена классов, методов и свойств (оставляйте как в API)

  • ❌ Синтаксис RST (директивы, роли)

  • ❌ Код (сами примеры кода не переводятся)

Инструменты для перевода

Для редактирования файлов .po рекомендуется использовать:

  • Poedit (рекомендуется для начинающих)

    # Install on Ubuntu
sudo apt install poedit

# macOS
brew install poedit

  • Lokalize (для продвинутых пользователей)

  • Любой текстовый редактор — файлы .po можно редактировать в любом текстовом редакторе

Пример перевода

Исходный файл (basics/getting-started.rst):

Getting Started
===============

Thunder Engine is a powerful game engine designed for modern
game development.

Соответствующий файл .po после перевода на русский:

#: ../../basics/getting-started.rst:1
msgid "Getting Started"
msgstr "Начало работы"

#: ../../basics/getting-started.rst:3
msgid ""
"Thunder Engine is a powerful game engine designed for modern "
"game development."
msgstr ""
"Thunder Engine — это мощный игровой движок, разработанный для современной "
"разработки игр."

Проверка перевода¶

Сборка локализованной документации

# Build Russian version
make html-ru

# Or directly via sphinx-build
sphinx-build -b html -D language=ru . _build/ru

Проверка качества

Перед отправкой перевода проверьте:

  • [ ] Все строки переведены (нет пустых msgstr)

  • [ ] Синтаксис файла .po корректен:

    msgfmt --check locales/ru/LC_MESSAGES/*.po

  • [ ] Документация собирается без ошибок:

    make clean
make html-ru

  • [ ] Все ссылки работают (проверьте в браузере)

  • [ ] Терминология согласована по всему документу

  • [ ] Код в примерах не изменён

  • [ ] Специальные символы и форматирование сохранены

Отправка Pull Request¶

Шаг 1: Создайте ветку для перевода

git checkout -b docs/ru-translation

Шаг 2: Добавьте файлы перевода в репозиторий

# Add .po files for Russian
git add locales/ru/

# Add changes to Makefile (if a build target was added)
git add Makefile

# Commit the changes
git commit -m "docs: add Russian translation (initial)"

Шаг 3: Отправьте изменения в GitHub

git push origin docs/ru-translation

Шаг 4: Создайте Pull Request

При создании PR включите в описание:

## Localization: Russian

### What was done
- Added Russian translation of the documentation
- Created .po files in `locales/ru/LC_MESSAGES/`
- Added `html-ru` build target to Makefile

### Translation status
- [x] basics/ — 100%
- [x] rendering/ — 100%
- [ ] scripting/ — 50% (in progress)
- [x] components/ — 100%

### Verification
- [x] `msgfmt` passes without errors
- [x] Documentation builds successfully
- [x] All links work

### Screenshots
![Russian version build](url)

Шаг 5: Ответьте на комментарии рецензента

После создания PR рецензент проверит:

  • Правильность перевода технических терминов

  • Качество перевода (грамматика, стиль)

  • Сохранение форматирования

  • Работоспособность ссылок

Обновление переводов¶

Когда исходная документация обновляется, переводы также необходимо обновлять:

Шаг 1: Обновите шаблоны

# Generate new templates
sphinx-build -b gettext source/ _build/gettext

Шаг 2: Обновите существующие переводы

# Update .po files for Russian
sphinx-intl update -p _build/gettext -l ru

Шаг 3: Переведите новые строки

В файлах .po появятся новые записи с пустым msgstr. Их необходимо перевести.

Шаг 4: Отправьте обновления

git add locales/ru/
git commit -m "docs: update Russian translation"
git push

Контрольный список для добавления новой локализации¶

  1. Create structure - Create .po files for all documents - Add build target to Makefile

  2. Translation - All strings are translated - Terminology is consistent - Code comments are translated

  3. Verification - msgfmt produces no errors - Documentation builds without warnings - All links work - Formatting is preserved

  4. Submission - Branch created with descriptive name - Commit with message docs: add [language] translation - Pull Request created with translation status description

Как стать переводчиком¶

  1. Выберите язык для перевода (русский, китайский, немецкий и т.д.)

  2. Проверьте, существует ли уже активный перевод для этого языка

  3. Создайте Issue в репозитории thunder-doc, указав своё намерение переводить

  4. Следуйте инструкциям выше, чтобы создать файлы перевода

  5. Начните с одного документа — вам не нужно переводить всё сразу

  6. Отправьте PR даже с частичным переводом — другие могут помочь продолжить

Совет

Даже перевод одного документа — это ценный вклад! Не бойтесь начинать с малого.
