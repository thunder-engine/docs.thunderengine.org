Сборка Thunder Engine из исходников¶

Получение исходного кода¶

На данный момент исходный код Thunder Engine размещён по адресу https://github.com/thunder-engine/thunder и может быть получен несколькими способами:

  1. Для получения полного репозитория разработчика используйте утилиту Git

git clone https://github.com/thunder-engine/thunder.git

  1. Или используя официальную утилиту GitHub https://desktop.github.com/

  2. Для получения стабильного релиза используйте страницу релизов

  3. Для получения последнего снапшота разработчика используйте эту ссылку

Необходимое программное обеспечение¶

Перед сборкой Thunder Engine из исходников убедитесь, что следующее программное обеспечение установлено и доступно в вашем окружении:

  • Git — для клонирования репозитория.

  • QBS (qbs) — инструмент сборки, используемый проектом; обратите внимание, что последние версии Qt Creator включают qbs (вы также можете установить qbs отдельно). Убедитесь, что он находится в вашем PATH, или используйте инструменты Qt Creator.

  • CMake — альтернативная, широко используемая система сборки; рекомендуется cmake (>=3.16).

  • Qt — для каждой платформы требуются соответствующие версии Qt (в примерах ниже используется Qt 6.7.3).

  • Инструментальная цепочка C++:

    • Windows: Microsoft Visual Studio 2022 или новее (инструментальная цепочка MSVC).

    • Linux: инструментальная цепочка GCC или Clang (установите build-essential или эквивалент).

    • macOS: Xcode и инструменты командной строки.

  • Qt Creator — опционально, полезен для редактирования и отладки (в примерах указаны версии Qt Creator).

  • Дополнительные утилиты: wget, 7z (для примера на macOS), bash в Windows (WSL или Git Bash), где применимо.

Убедитесь, что соответствующие бинарные файлы инструментов (например, qmake, qbs, инструменты компилятора) доступны в вашем PATH перед началом сборки.

Сборка для Windows¶

  1. Для сборки Thunder Engine из исходников в Windows вам потребуется настроить дополнительное окружение:

    • Microsoft Visual Studio 2022 или выше (вы можете бесплатно скачать Community Edition)

    • Qt 6.7.3 и Qt Creator 13.0.1

  2. После установки всего необходимого программного обеспечения откройте консоль «Command Prompt», перейдите в каталог с исходным кодом Thunder Engine и выполните последовательность команд ниже.

  3. Добавьте фреймворк Qt в PATH. Например:

thunder> set PATH=%PATH%;C:\Qt\6.7.3\msvc2015\bin

  1. Запустите процедуру сборки

thunder> qbs setup-toolchains --detect
thunder> qbs setup-qt C:\Qt\6.7.3\msvc2015\bin\qmake.exe qt
thunder> qbs config defaultProfile qt
thunder> qbs build --all-products config:release

Сборка с помощью CMake¶

Thunder Engine также можно настроить и собрать с помощью CMake. Ниже приведены общие примеры — адаптируйте переменные и имена генераторов к вашему окружению.

Общие шаги (кроссплатформенные):

# from project root
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

Windows (генератор Visual Studio):

cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_BUILD_TYPE=Release
cmake --build build --config Release

macOS / Linux (Ninja или Unix Makefiles):

cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build -- -j$(nproc)

Примечания:

  • Если проект требует Qt, укажите CMake путь к вашей установке Qt через -DQt5_DIR= или -DQt6_DIR= соответственно.

  • Используйте -G «Ninja» для более быстрой параллельной сборки, когда установлен Ninja.

  • Замените $(nproc) на соответствующую команду подсчёта CPU в macOS (sysctl -n hw.ncpu).

Сборка для OS X¶

  1. Установите последнюю версию XCode

  2. Откройте консольное приложение, перейдите в каталог с исходным кодом Thunder Engine

  3. Установите homebrew

  4. Соберите Thunder Engine с помощью последовательности команд ниже.

$ export QT_INSTALL_DIR=~/Qt
$ export QT_VERSION=6.7.3
$ export QT_BIN=$QT_INSTALL_DIR/$QT_VERSION/clang_64/bin
$ export PATH=$QT_INSTALL_DIR/Qt Creator.app/Contents/MacOS:$QT_BIN:$PATH
$ bash ./build/install-qt.sh -d $QT_INSTALL_DIR --version $QT_VERSION qtbase qt5compat qtsvg qtimageformats qtxmlpatterns qtdeclarative
# Download and install Qt Creator 13.0.1 from the official Qt downloads for your platform.
# Example (replace with an appropriate URL for your platform):
# $ wget https://download.qt.io/official_releases/qtcreator/13.0/13.0.1/qtcreator-13.0.1-macos-x64.7z
$ 7z x -y -o${QT_INSTALL_DIR} qtcreator.7z
$ qbs --version
$ qbs setup-toolchains --detect
$ qbs setup-qt $QT_BIN/qmake qt-brew
$ qbs install --all-products config:release profile:qt-brew

(Опционально) Чтобы собрать Thunder Engine для iOS и tvOS, выполните дополнительные команды ниже.

$ qbs resolve config:release profile:xcode-iphoneos-arm64
$ qbs install --all-products config:release profile:xcode-iphoneos-arm64
$ qbs resolve config:release profile:xcode-appletvos-arm64
$ qbs install --all-products config:release profile:xcode-appletvos-arm64

Сборка для Linux¶

Откройте консоль, перейдите в каталог с исходным кодом Thunder Engine и выполните последовательность команд ниже.

$ export QT_INSTALL_DIR=~/Qt
$ export QT_VERSION=6.7.3
$ export QTCREATOR_VERSION=13.0.1
$ export QT_BIN=${QT_INSTALL_DIR}/${QT_VERSION}/gcc_64/bin
$ export PATH="$QT_INSTALL_DIR/Tools/QtCreator/bin:$QT_BIN:$PATH"
$ bash ./build/install-qt.sh -d $QT_INSTALL_DIR --version ${QT_VERSION} qtbase qtsvg qtimageformats qttools qtxmlpatterns qtdeclarative qtgamepad icu
$ bash ./build/install-qt.sh -d $QT_INSTALL_DIR --version ${QTCREATOR_VERSION} qtcreator
$ qbs setup-toolchains --detect
$ qbs setup-qt --detect
$ qbs config defaultProfile
$ qbs install --all-products config:release
