Установка Thunder Engine¶

Thunder Engine состоит из набора фреймворков и инструментов. Thunder Engine имеет модульную структуру, поэтому разработчики могут выбирать именно те модули, которые им нужны.

Thunder Engine можно установить двумя способами:

Используя страницу Релизов (предпочтительно)

Чтобы загрузить последний релиз, перейдите по этой ссылке

Сборка движка из исходных кодов¶

Получение исходного кода¶

На данный момент исходный код Thunder Engine размещён по адресу https://github.com/thunder-engine/thunder и может быть получен несколькими способами:

  1. Чтобы получить полный репозиторий для разработчика, используйте утилиту Git

git clone https://github.com/thunder-engine/thunder.git

  1. Или используя официальную утилиту GitHub https://desktop.github.com/

  2. Чтобы получить стабильный релиз, используйте страницу Релизов

  3. Чтобы получить последний снимок для разработчика, используйте эту ссылку

Сборка для Windows¶

  1. Для сборки Thunder Engine из исходных кодов в Windows вам потребуется настроить дополнительное окружение:

    • Microsoft Visual Studio 2022 или выше (вы можете бесплатно загрузить версию Community Edition)

    • Qt 5.15.2 и QtCreator 4.9.2

  2. После установки всего необходимого программного обеспечения откройте консоль «Командная строка», перейдите в каталог с исходным кодом Thunder Engine и выполните приведённую ниже последовательность команд.

  3. Добавьте Qt framework в PATH. Например:

thunder> set PATH=%PATH%;C:\Qt\5.15.2\msvc2015\bin

  1. Запустите процедуру сборки

thunder> qbs setup-toolchains --detect
thunder> qbs setup-qt C:\Qt\5.15.2\msvc2015\bin\qmake.exe qt
thunder> qbs config defaultProfile qt
thunder> qbs build --all-products config:release

Сборка для OS X¶

  1. Установите последнюю версию XCode

  2. Откройте приложение Консоль, перейдите в каталог с исходным кодом Thunder Engine

  3. Установите homebrew

  4. Соберите Thunder Engine, выполнив приведённую ниже последовательность команд.

$ export QT_INSTALL_DIR=~/Qt
$ export QT_VERSION=6.7.2
$ export QT_BIN=$QT_INSTALL_DIR/$QT_VERSION/clang_64/bin
$ export PATH=$QT_INSTALL_DIR/Qt Creator.app/Contents/MacOS:$QT_BIN:$PATH
$ bash ./build/install-qt.sh -d $QT_INSTALL_DIR --version $QT_VERSION qtbase qt5compat qtsvg qtimageformats qtxmlpatterns qtdeclarative
$ wget https://download.qt.io/official_releases/qtcreator/4.9/4.9.2/installer_source/mac_x64/qtcreator.7z
$ 7z x -y -o${QT_INSTALL_DIR} qtcreator.7z
$ qbs --version
$ qbs setup-toolchains --detect
$ qbs setup-qt $QT_BIN/qmake qt-brew
$ qbs install --all-products config:release profile:qt-brew

(Опционально) Чтобы собрать Thunder Engine для iOS и tvOS, выполните дополнительные команды ниже.

$ qbs resolve config:release profile:xcode-iphoneos-arm64
$ qbs install --all-products config:release profile:xcode-iphoneos-arm64
$ qbs resolve config:release profile:xcode-appletvos-arm64
$ qbs install --all-products config:release profile:xcode-appletvos-arm64

Сборка для Linux¶

Откройте консоль, перейдите в каталог с исходным кодом Thunder Engine и выполните приведённую ниже последовательность команд.

$ export QT_INSTALL_DIR=~/Qt
$ export QT_VERSION=5.15.2
$ export QTCREATOR_VERSION=5.0.3
$ export QT_BIN=${QT_INSTALL_DIR}/${QT_VERSION}/gcc_64/bin
$ export PATH="$QT_INSTALL_DIR/Tools/QtCreator/bin:$QT_BIN:$PATH"
$ bash ./build/install-qt.sh -d $QT_INSTALL_DIR --version ${QT_VERSION} qtbase qtsvg qtimageformats qttools qtxmlpatterns qtdeclarative qtgamepad icu
$ bash ./build/install-qt.sh -d $QT_INSTALL_DIR --version ${QTCREATOR_VERSION} qtcreator
$ qbs setup-toolchains --detect
$ qbs setup-qt --detect
$ qbs config defaultProfile
$ qbs install --all-products config:release
