RectTransform¶

Наследует: Transform

Описание¶

Класс ProgressBar предназначен для предоставления графического представления прогресса с настраиваемым внешним видом и диапазоном. Он поддерживает такие функции, как установка минимального и максимального значений, настройка значения прогресса и указание визуальных элементов для фона и индикатора прогресса.

Описание методов¶

Vector4 RectTransform::border () const

Возвращает ширину границы RectTransform. Vector4 содержит ширины границ в порядке top, right, bottom и left.

См. также setBorder().

Vector4 RectTransform::clipRegion () const

Возвращает внутреннюю область отсечения. Всё содержимое за пределами этой области не будет отрисовано.

RectTransform::SizePolicy RectTransform::horizontalPolicy () const

Возвращает политику горизонтального размера.

См. также setHorizontalPolicy().

Layout * RectTransform::layout () const

Возвращает layout, назначенный RectTransform.

См. также setLayout().

Vector2 RectTransform::mapFromGlobal (float x, float y)

Преобразует глобальные экранные координаты x и y в пространство виджета.

Vector4 RectTransform::margin () const

Возвращает отступы margin RectTransform. Vector4 содержит отступы в порядке top, right, bottom и left.

См. также setMargin().

Vector2 RectTransform::maxAnchors () const

Возвращает максимальные якоря RectTransform.

См. также setMaxAnchors().

Vector2 RectTransform::minAnchors () const

Возвращает минимальные якоря RectTransform.

См. также setMinAnchors().

Vector4 RectTransform::padding () const

Возвращает отступы padding RectTransform. Vector4 содержит отступы padding в порядке top, right, bottom и left.

См. также setPadding().

Vector2 RectTransform::pivot () const

Возвращает точку pivot RectTransform.

См. также setPivot().

void RectTransform::setAnchors (Vector2 & minimum, Vector2 & maximum)

Устанавливает и минимальные (minimum), и максимальные (maximum) якоря RectTransform.

void RectTransform::setBorder (Vector4 & border)

Устанавливает ширину border сверху, справа, снизу и слева для RectTransform.

См. также border().

void RectTransform::setEnabled (bool enabled)

Переопределяет: Component::setEnabled(bool enabled).

Устанавливает текущее состояние RectTransform в enabled или отключённое.

void RectTransform::setHorizontalPolicy (RectTransform::SizePolicy policy)

Устанавливает политику горизонтального размера.

См. также horizontalPolicy().

void RectTransform::setLayout (Layout * layout)

Устанавливает layout для RectTransform.

См. также layout().

void RectTransform::setMargin (Vector4 & margin)

Устанавливает margin отступы сверху, справа, снизу и слева для RectTransform.

См. также margin().

void RectTransform::setMaxAnchors (Vector2 & anchors)

Устанавливает максимальные anchors RectTransform.

См. также maxAnchors().

void RectTransform::setMinAnchors (Vector2 & anchors)

Устанавливает минимальные anchors RectTransform.

См. также minAnchors().

void RectTransform::setPadding (Vector4 & padding)

Устанавливает padding отступы сверху, справа, снизу и слева для RectTransform.

См. также padding().

void RectTransform::setPivot (Vector2 & pivot)

Устанавливает pivot точку RectTransform.

См. также pivot().

void RectTransform::setPosition (Vector3 & position)

Переопределяет: Transform::setPosition(const Vector3 &position).

Изменяет position Transform в локальном пространстве.

void RectTransform::setRotation (Vector3 & angles)

Переопределяет: Transform::setRotation(const Vector3 &angles).

Изменяет angles вращения Transform в локальном пространстве.

void RectTransform::setScale (Vector3 & scale)

Переопределяет: Transform::setScale(const Vector3 &scale).

Изменяет scale Transform в локальном пространстве.

void RectTransform::setSize (Vector2 & size)

Устанавливает size RectTransform.

См. также size().

void RectTransform::setVerticalPolicy (RectTransform::SizePolicy policy)

Устанавливает политику вертикального размера.

См. также verticalPolicy().

Vector2 RectTransform::size () const

Возвращает размер связанного элемента UI.

См. также setSize().

Vector2 RectTransform::sizeHint () const

Возвращает рекомендуемый размер для размещения всего видимого содержимого.

void RectTransform::subscribe (Widget * widget)

Подписывает widget на изменения в RectTransform.

void RectTransform::unsubscribe (Widget * widget)

Отписывает widget от изменений в RectTransform.

RectTransform::SizePolicy RectTransform::verticalPolicy () const

Возвращает политику вертикального размера.

См. также setVerticalPolicy().

Widget * RectTransform::widget ()

Возвращает первый виджет, связанный с этим rect transform.

std::list<Widget *> & RectTransform::widgets ()

Возвращает список виджетов, связанных с этим rect transform
