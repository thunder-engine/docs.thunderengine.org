Engine¶

Наследует: ObjectSystem

Описание¶

Класс Engine — одна из центральных частей Thunder Engine. Этот класс создаётся первым и удаляется последним в вашей игре. Он отвечает за многие базовые функции, такие как игровой цикл, управление игровыми модулями, загрузка и выгрузка игровых ресурсов, работа с настройками игры.

Описание методов¶

Engine::Engine ()

Создаёт Engine.

Engine::~Engine ()

Разрушает Engine, связанные объекты, зарегистрированные фабрики объектов и платформенный адаптер.

void Engine::addModule (Module * module)

Добавляет игровой module в пул. Этот module будет использоваться во время выполнения метода update().

Пример:

if(engine->init()) {
    Engine::addModule(new RenderGL(engine));

    engine->start();
}

TString Engine::applicationName ()

Возвращает имя этого приложения. Это имя используется для создания пути к настройкам и журналам этого приложения.

См. также setApplicationName().

TString Engine::applicationVersion ()

Возвращает версию этого приложения.

См. также setApplicationVersion().

Actor * Engine::composeActor (TString & component, TString & name, Object * parent = nullptr)

Создаёт Actor с name и прикреплённым компонентом. Созданный Actor будет добавлен в иерархию parent. Этот метод помогает создать все зависимости для компонента.

Предупреждение: Этот метод следует использовать только в режиме редактора.

System * Engine::getSystem (TString & name)

Возвращает подсистему с указанным именем.

bool Engine::init ()

Инициализирует все системы движка. Возвращает true в случае успеха; иначе возвращает false.

Engine & Engine::instance ()

Возвращает экземпляр объекта Engine.

bool Engine::isGameMode ()

Возвращает true, если игра запущена; иначе возвращает false.

bool Engine::isResourceExist (TString & path)

Возвращает true, если ресурс с path существует; иначе возвращает false.

Resource * Engine::loadResource (TString & path)

Возвращает экземпляр для загрузки ресурса по указанному пути.

Примечание: Если ресурс был загружен ранее, эта функция вернёт тот же экземпляр.

См. также unloadResource().

Resource * Engine::loadResourceAsync (TString & path)

Возвращает экземпляр для загрузки ресурса по указанному пути. Ресурс будет загружен асинхронно. Это означает, что перед использованием следует проверить состояние ресурса.

Примечание: Если ресурс был загружен ранее, эта функция вернёт тот же экземпляр.

См. также unloadResource().

bool Engine::loadTranslator (TString & name)

Загружает таблицу переводов с указанным именем файла. Этот метод генерирует событие LanguageChange для экземпляра Engine. Экземпляр Engine распространит событие на все виджеты верхнего уровня, где переопределение event() может повторно перевести видимые пользователю строки. Возвращает true в случае успеха; иначе возвращает false.

TString Engine::locationAppConfig ()

Возвращает путь к каталогу конфигурации приложения.

TString Engine::organizationName ()

Возвращает имя организации, написавшей это приложение. Это имя используется для создания пути к настройкам и журналам этого приложения.

См. также setOrganizationName().

PlatformAdaptor * Engine::platformAdaptor ()

Возвращает текущий платформенный адаптер.

См. также setPlatformAdaptor().

TString Engine::reference (Object * object)

Возвращает путь к ресурсу для указанного объекта ресурса.

void Engine::reloadResource (TString & path)

Перезагружает ресурс, расположенный по указанному пути.

См. также loadResource().

RenderSystem * Engine::renderSystem ()

Возвращает систему рендеринга, которая может использоваться во внешних модулях.

ResourceSystem * Engine::resourceSystem ()

Возвращает систему управления ресурсами, которая может использоваться во внешних модулях.

void Engine::setApplicationName (TString & name)

Устанавливает name этого приложения.

См. также applicationName().

void Engine::setApplicationVersion (TString & version)

Устанавливает version этого приложения.

См. также applicationVersion().

void Engine::setGameMode (bool flag)

Устанавливает игровой flag в true, если игра запущена; иначе устанавливает false.

См. также isGameMode().

void Engine::setOrganizationName (TString & name)

Устанавливает name организации, написавшей это приложение.

См. также organizationName().

bool Engine::setPlatformAdaptor (PlatformAdaptor * platform)

Заменяет текущий platform адаптер новым; Возвращает true, если замена прошла успешно; иначе возвращает false.

Примечание: Предыдущий platform адаптер не будет удалён.

См. также platformAdaptor().

void Engine::setValue (TString & key, Variant & value)

Устанавливает value настройки key в value. Если key уже существует, предыдущее value будет перезаписано.

См. также value().

bool Engine::start ()

Запускает основной игровой цикл. Также этот метод загружает первый уровень вашей игры. Возвращает true в случае успеха; иначе возвращает false.

void Engine::syncValues ()

Применяет все несохранённые настройки.

TString Engine::translate (TString & text)

Возвращает перевод текста.

void Engine::unloadResource (TString & path)

Принудительно выгружает ресурс, расположенный по path, из памяти.

Warning: After this call, the reference on the resource may become an invalid at any time and must not be used anymore.

См. также loadResource().

void Engine::unloadResource (Resource * resource)

Forcely unloads the resource from memory.

Warning: After this call, the reference on the resource may become an invalid at any time and must not be used anymore.

См. также loadResource().

void Engine::update (World * world)

This method launches all your game modules responsible for processing all the game logic. It calls on each iteration of the game cycle for the particular world.

Note: Usually, this method calls internally and must not be called manually.

Variant Engine::value (TString & key, Variant & defaultValue = Variant())

Returns the value for setting key. If the setting doesn’t exist, returns defaultValue.

See also setValue().

World * Engine::world ()

Returns game World.

Note: The game can have only one scene graph. World is a root object, all map loads on this World.
