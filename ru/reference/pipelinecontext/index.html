PipelineContext¶

Наследует: Object

Описание¶

PipelineContext — класс, отвечающий за управление контекстом конвейера рендеринга, включая задачи рендеринга, настройки камеры и эффекты постобработки.

Описание методов¶

void PipelineContext::addTextureBuffer (Texture * texture)

Добавляет буфер texture к глобальным текстурам в командном буфере.

CommandBuffer * PipelineContext::buffer () const

Извлекает командный буфер, связанный с контекстом конвейера.

void PipelineContext::cameraReset ()

Сбрасывает матрицы вида и проекции камеры в командном буфере.

std::list<std::pair<const PostProcessSettings , :ref:`float>><api_float>>>` & **PipelineContext::culledPostEffectSettings* ()

Возвращает список отфильтрованных настроек постобработки сцены, относящихся к рендерингу.

RenderList PipelineContext::culledRenderables ()

Возвращает список отсечённых компонентов сцены на основе отсечения по усечённой пирамиде.

Camera * PipelineContext::currentCamera () const

Возвращает текущую установленную камеру для рендеринга.

См. также setCurrentCamera().

Mesh * PipelineContext::defaultCube ()

Возвращает стандартный кубический меш, используемый при рендеринге.

Mesh * PipelineContext::defaultPlane ()

Извлекает стандартный меш плоскости, используемый при рендеринге.

RenderTarget * PipelineContext::defaultTarget ()

Возвращает целевой объект рендеринга по умолчанию, связанный с контекстом конвейера.

См. также setDefaultTarget().

void PipelineContext::frustumCulling (Frustum & frustum, RenderList & in, RenderList & out)

Фильтрует out входящий список in, который не находится в in усечённой пирамиде. Возвращает отфильтрованный список.

void PipelineContext::insertRenderTask (PipelineTask * task, PipelineTask * before = nullptr)

Вставляет задачу рендеринга task в контекст конвейера. При необходимости указывает task, перед которой нужно вставить.

void PipelineContext::invalidateTasks ()

Аннулирует все задачи конвейера, чтобы позволить им восстановить соединения.

int32_t PipelineContext::lod (float size)

Возвращает уровень LOD на основе нормализованного процентного размера size объекта на экране.

const std::list<PipelineTask *> & PipelineContext::renderTasks () const

Возвращает список задач рендеринга, связанных с контекстом конвейера.

StringList PipelineContext::renderTextures () const

Возвращает список имён глобальных текстур.

void PipelineContext::resize (int32_t width, int32_t height)

Изменяет размер контекста конвейера до указанных width и height. Соответственно обновляет задачи рендеринга.

Texture * PipelineContext::resultTexture ()

Возвращает результирующую текстуру, содержащую результат рендеринга.

LightList PipelineContext::sceneLights ()

Возвращает список источников света сцены, относящихся к рендерингу.

RenderList PipelineContext::sceneRenderables ()

Возвращает список компонентов сцены, относящихся к рендерингу.

void PipelineContext::setCurrentCamera (Camera * camera)

Устанавливает текущую camera и обновляет связанные матрицы в командном буфере.

См. также currentCamera().

void PipelineContext::setDefaultTarget (RenderTarget * target)

Устанавливает целевой объект рендеринга target по умолчанию для контекста конвейера.

См. также defaultTarget().

void PipelineContext::setPipeline (Pipeline * pipeline)

Устанавливает pipeline рендеринга для контекста, создавая и связывая соответствующие задачи рендеринга.

void PipelineContext::setWorld (World * world)

Устанавливает текущий экземпляр world для обработки.

См. также world().

Vector2 PipelineContext::size () const

Возвращает размер экрана

void PipelineContext::subscribePost (PipelineContext::RenderCallback callback, void * object)

Подписывает callback для object на обработку этапа постобработки.

Texture * PipelineContext::textureBuffer (TString & name)

Возвращает буфер текстуры по её имени.

void PipelineContext::unsubscribePost (void * object)

Отписывает object от обработки этапа постобработки.

Texture * PipelineContext::whiteTexture ()

Возвращает белую текстуру, используемую при рендеринге.

World * PipelineContext::world ()

Возвращает текущий экземпляр world для обработки.

См. также setWorld().
