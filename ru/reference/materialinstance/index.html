MaterialInstance¶

Наследует: None

Описание¶

Класс MaterialInstance позволяет настраивать параметры материала и текстуры для рендеринга объектов. Он поддерживает различные типы параметров, и настройка может выполняться для каждого экземпляра отдельно.

Нет

Описание методов¶

int32_t MaterialInstance::finalPriority () const

Возвращает итоговый приоритет экземпляра материала, используемый для сортировки очереди рендеринга. Вычисляется как Material::priority + priority

uint32_t MaterialInstance::instanceCount () const

Возвращает количество GPU-экземпляров для рендеринга.

См. также setInstanceCount().

uint32_t MaterialInstance::instanceSize () const

Возвращает размер данных для экземпляров.

Material * MaterialInstance::material () const

Геттер базового материала, связанного с экземпляром.

void MaterialInstance::overrideTexture (int32_t binding, Texture * texture)

Переопределяет texture для указанной точки binding шейдера.

int32_t MaterialInstance::priority () const

Возвращает приоритет экземпляра.

См. также setPriority().

ByteArray MaterialInstance::rawUniformBuffer ()

Возвращает ссылку на CPU-часть униформ-буфера. Разработчик может изменять её по своим потребностям.

void MaterialInstance::setBool (TString & name, bool * value)

Устанавливает булев параметр с опциональной поддержкой массива. Параметр name задаёт name булева параметра. Параметр value — указатель на булево value или массив булевых значений.

void MaterialInstance::setBufferValue (TString & name, void * value)

Устанавливает value параметра с указанным name в униформ-буфере.

void MaterialInstance::setFloat (TString & name, float * value)

Устанавливает float-параметр с опциональной поддержкой массива. Параметр name задаёт name float-параметра. Параметр value — указатель на float value или массив float-значений.

void MaterialInstance::setInstanceBuffer (ByteArray * buffer)

Устанавливает буфер экземпляров.

void MaterialInstance::setInstanceCount (uint32_t number)

Устанавливает number GPU-экземпляров для рендеринга.

См. также instanceCount().

void MaterialInstance::setInteger (TString & name, int32_t * value)

Устанавливает целочисленный параметр с опциональной поддержкой массива. Параметр name задаёт name целочисленного параметра. Параметр value — указатель на целочисленное value или массив целочисленных значений.

void MaterialInstance::setMatrix4 (TString & name, Matrix4 * value)

Устанавливает параметр Matrix4 с опциональной поддержкой массива. Параметр name задаёт name параметра Matrix4. Параметр value — указатель на value Matrix4 или массив значений Matrix4.

void MaterialInstance::setPriority (int32_t priority)

Устанавливает приоритет экземпляра.

См. также priority().

void MaterialInstance::setSkinSize (uint32_t size)

Устанавливает размер буфера костей скелетного меша. Этот буфер должен быть записан в конец структуры данных экземпляра (после всех униформ).

void MaterialInstance::setSurfaceType (uint16_t type)

Устанавливает type поверхности, связанный с экземпляром материала.

См. также surfaceType().

void MaterialInstance::setTexture (TString & name, Texture * texture)

Устанавливает параметр texture с указанным именем.

См. также texture().

void MaterialInstance::setTransform (Matrix4 & transform, uint32_t uuid, uint32_t hash)

Устанавливает матрицу transform. Обновление выполняется только тогда, когда значение hash отличается от текущего сохранённого хеша преобразования.

uuid используется для генерации идентифицирующего цвета. Если ноль, встраивание цвета не выполняется.

void MaterialInstance::setVector2 (TString & name, Vector2 * value)

Устанавливает параметр Vector2 с опциональной поддержкой массива. Параметр name задаёт name параметра Vector2. Параметр value — указатель на value Vector2 или массив значений Vector2.

void MaterialInstance::setVector3 (TString & name, Vector3 * value)

Устанавливает параметр Vector3 с опциональной поддержкой массива. Параметр name задаёт name параметра Vector3. Параметр value — указатель на value Vector3 или массив значений Vector3.

void MaterialInstance::setVector4 (TString & name, Vector4 * value)

Устанавливает параметр Vector4 с опциональной поддержкой массива. Параметр name задаёт name параметра Vector4. Параметр value — указатель на value Vector4 или массив значений Vector4.

uint16_t MaterialInstance::surfaceType () const

Получает тип поверхности, связанный с экземпляром материала.

См. также setSurfaceType().

Texture * MaterialInstance::texture (CommandBuffer & buffer, int32_t binding)

Геттер переопределённой текстуры, связанной с определённой точкой binding параметра.

Командный buffer, используемый для разрешения текстур и доступа к ресурсам.

См. также setTexture().
