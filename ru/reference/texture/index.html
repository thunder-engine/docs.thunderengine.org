Texture¶

Наследует: Resource

Описание¶

Этот класс можно использовать для работы с текстурным ресурсом или создания их во время выполнения.

Публичные перечисления¶

enum Texture::FilteringType

Константа

Значение

Описание

Texture::None

0

Сэмплы текстуры отрисовываются как есть.

Texture::Bilinear

1

Сэмплы текстуры усредняются.

Texture::Trilinear

2

Сэмплы текстуры усредняются и также интерполируются из соседних уровней мипмапов.

enum Texture::Flags

Константа

Значение

Описание

Texture::Render

(1<<0)

Эта текстура используется в качестве цели рендеринга во фреймбуферах.

Texture::Feedback

(1<<1)

Feedback-текстуры могут читать данные с GPU на CPU.

enum Texture::FormatType

Константа

Значение

Описание

Texture::R8

0

Одноканальная (красная) текстура. 8-битное целое

Texture::RGB8

1

Формат цветной текстуры. 8-битное целое на канал. Всего 24 бита.

Texture::RGBA8

2

Формат цветной текстуры с альфа-каналом. 8-битное целое на канал. Всего 32 бита.

Texture::RGB10A2

3

10 бит на каждый из RGB, 2 на Alpha.

Texture::R11G11B10Float

4

Использует специальные 11- и 10-битные значения с плавающей запятой. Это очень экономично для значений с плавающей запятой (используется только 32 бита на значение).

Texture::RGBA32Float

5

Цветная текстура и альфа со значениями с плавающей запятой. Использует 32-битные значения с плавающей запятой на канал.

Texture::RGBA16Float

6

Цветная текстура и альфа со значениями с плавающей запятой. Использует 16-битные значения с плавающей запятой на канал.

Texture::Depth

7

Формат текстуры буфера глубины. Количество бит на пиксель зависит от графических настроек и оборудования. Может быть 16, 24 или 32 бита на пиксель.

enum Texture::WrapType

Режим обёртки для текстур.

Константа

Значение

Описание

Texture::Clamp

0

Ограничивает текстуру последним пикселем на краю.

Texture::Repeat

1

Размножает текстуру, создавая повторяющийся узор.

Texture::Mirrored

2

Размножает текстуру, создавая повторяющийся узор путём зеркального отражения на каждой целочисленной границе.

Описание методов¶

void Texture::addSurface (Texture::Surface & surface)

Добавляет surface к текстуре. Каждая текстура должна содержать хотя бы одну surface.

int Texture::compress () const

Возвращает метод сжатия.

См. также setCompress().

int Texture::depth () const

Возвращает измерение глубины для текстуры.

См. также setDepth().

int Texture::depthBits () const

Возвращает количество бит буфера глубины.

Примечание: Это значение действительно только для текстур глубины.

См. также setDepthBits().

int Texture::filtering () const

Возвращает тип фильтрации текстуры. Подробности см. в перечислении Texture::FilteringType.

См. также setFiltering().

int Texture::flags () const

Возвращает служебные флаги для текстуры.

См. также setFlags() и Texture::Flags.

int Texture::format () const

Возвращает тип формата текстуры. Подробности см. в перечислении Texture::FormatType.

См. также setFormat().

int Texture::getPixel (int x, int y, int level) const

Возвращает цвет пикселя из мип-level в позиции x и y в виде целого числа RGBA, например 0x00ff00ff, которое можно сопоставить с (0, 255, 0, 255)

ByteArray Texture::getPixels (int level) const

Возвращает данные текстуры с уровня мипмапа.

int Texture::height () const

Возвращает высоту текстуры.

См. также setHeight().

bool Texture::isArray () const

Возвращает true, если текстура предоставляет набор текстур; иначе возвращает false.

Примечание: На данный момент всегда возвращает false.

bool Texture::isCubemap () const

Возвращает true, если текстура является кубической картой; иначе false.

bool Texture::isFeedback () const

Возвращает true, если текстура помечена как feedback-текстура; иначе возвращает false. Feedback-текстуры могут читать данные с GPU на CPU.

bool Texture::isRender () const

Возвращает true, если текстура может быть прикреплена к фреймбуферу; иначе возвращает false.

uint32_t Texture::maxCubemapSize ()

Возвращает максимальный размер кубической карты.

uint32_t Texture::maxTextureSize ()

Возвращает максимальный размер текстуры.

int Texture::mipCount () const

Возвращает количество уровней MIP.

См. также setMipCount().

void Texture::readPixels (int x, int y, int width, int height)

Читает пиксели с GPU в позиции x и y с размерами width и height в данные текстуры.

void Texture::resize (int width, int height)

Устанавливает новые width и height для текстуры.

void Texture::setCompress (int method)

Устанавливает метод сжатия.

См. также compress().

void Texture::setDepth (int depth)

Устанавливает новое измерение depth для текстуры.

См. также depth().

void Texture::setDepthBits (int depth)

Устанавливает количество бит буфера depth.

Примечание: Это значение действительно только для текстур depth.

См. также depthBits().

void Texture::setDirty ()

Marks texture as dirty. That means this texture must be forcefully reloaded.

void Texture::setFiltering (int type)

Sets filtering type of texture. For more details please see the Texture::FilteringType enum.

See also filtering().

void Texture::setFlags (int flags)

Sets service flags for the texture.

See also flags() and Texture::Flags.

void Texture::setFormat (int type)

Sets format type of texture. For more details please see the Texture::FormatType enum.

See also format().

void Texture::setHeight (int height)

Sets new height for the texture.

See also height().

void Texture::setMipCount (int levels)

Sets the number of MIP levels.

See also mipCount().

void Texture::setWidth (int width)

Sets new width for the texture.

See also width().

void Texture::setWrap (int type)

Sets the type of warp policy. For more details please see the Texture::WrapType enum.

See also wrap().

int Texture::sides () const

Returns the number of texture sides. In most cases returns 1 but for the cube map will return 6

Texture::Surface & Texture::surface (int side)

Returns a surface for the provided side. Each texture must contain at least one surface. Commonly used to set surfaces for the cube maps.

int Texture::width () const

Returns width for the texture.

See also setWidth().

int Texture::wrap () const

Returns the type of warp policy. For more details please see the Texture::WrapType enum.

See also setWrap().
