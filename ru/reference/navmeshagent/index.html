NavMeshAgent¶

Наследует: NativeBehaviour

Описание¶

Навигационный агент находит путь на навигационном меше и перемещает своего владельца по полученным путевым точкам. Агентом можно управлять, задавая целевую точку с помощью moveTo() или следуя за другим актёром с помощью moveToActor().

Агент использует настроенный agentType() для выбора совместимого навигационного меша. Его движение ограничено speed(), acceleration() и angularSpeed(). Когда autoBraking() включён, агент замедляется ближе к концу пути. Когда autoRepath() включён, он пересчитывает путь после обнаружения отклонения или остановки движения.

Публичные перечисления¶

enum NavMeshAgent::NavigationState

Описывает текущее состояние навигации агента.

Константа

Значение

Описание

NavMeshAgent::Idle

0

У агента нет активного навигационного запроса.

NavMeshAgent::Moving

1

Агент следует по текущему пути.

NavMeshAgent::Pathfinding

2

Агент вычисляет путь к своей цели.

NavMeshAgent::Stuck

3

Агент не перемещался в течение настроенного порога застревания.

NavMeshAgent::Arrived

4

Агент достиг места назначения.

Статические методы¶

Нет

Описание методов¶

NavMeshAgent::~NavMeshAgent ()

Уничтожает навигационного агента и останавливает его активный навигационный запрос.

float NavMeshAgent::acceleration () const

Возвращает максимальное ускорение движения в мировых единицах на секунду в квадрате.

См. также setAcceleration().

int NavMeshAgent::agentType () const

Возвращает тип агента навигационного меша, используемый для поиска пути.

Значение выбирает конфигурацию агента, зарегистрированную в NavigationSystem.

См. также setAgentType().

float NavMeshAgent::angularSpeed () const

Возвращает максимальную скорость вращения в градусах в секунду.

См. также setAngularSpeed().

bool NavMeshAgent::autoBraking () const

Возвращает true, когда агент автоматически замедляется ближе к концу своего пути.

См. также setAutoBraking().

bool NavMeshAgent::autoRepath () const

Возвращает true, когда агент автоматически пересчитывает отклонённый или остановившийся путь.

См. также setAutoRepath().

Vector3Vector NavMeshAgent::calculatePath (Vector3 & target)

Вычисляет путь от текущей позиции агента до точки target.

Возвращает пустой вектор, если путь не может быть найден.

См. также moveTo().

void NavMeshAgent::destinationReached ()

Испускается, когда агент достигает места назначения.

bool NavMeshAgent::moveTo (Vector3 & target)

Начинает перемещение агента к точке target.

Запрос заменяет текущий путь и испускает pathFound(), когда путь доступен, или pathFailed(), когда поиск пути не удался.

Возвращает true после отправки навигационного запроса.

См. также stop() и moveToActor().

bool NavMeshAgent::moveToActor (Actor * targetActor)

Начинает перемещение агента к позиции targetActor.

Возвращает false, если targetActor или его transform равен null. В противном случае возвращает результат moveTo().

См. также moveTo().

const Vector3Vector NavMeshAgent::path () const

Возвращает текущий путь как последовательность путевых точек.

void NavMeshAgent::pathFailed ()

Испускается, когда поиск пути не может построить путь к запрошенной цели.

void NavMeshAgent::pathFound ()

Испускается, когда путь к запрошенной цели найден.

void NavMeshAgent::pause (bool paused)

Приостанавливает или возобновляет движение в соответствии со paused.

Во время паузы текущий путь и состояние навигации сохраняются.

void NavMeshAgent::setAcceleration (float acceleration)

Устанавливает максимальное acceleration движения в мировых единицах на секунду в квадрате.

Значение acceleration ограничивает, насколько быстро может изменяться скорость движения.

См. также acceleration().

void NavMeshAgent::setAgentType (int type)

Устанавливает type агента навигационного меша, используемый для поиска пути.

Значение type — это индекс конфигурации агента, зарегистрированной в NavigationSystem.

См. также agentType().

void NavMeshAgent::setAngularSpeed (float angularSpeed)

Устанавливает максимальную скорость вращения в градусах в секунду.

Значение angularSpeed ограничивает вращение в градусах в секунду.

См. также angularSpeed().

void NavMeshAgent::setAutoBraking (bool autoBraking)

Включает или отключает автоматическое торможение ближе к концу пути.

Когда autoBraking равно true, агент замедляется ближе к концу пути.

См. также autoBraking().

void NavMeshAgent::setAutoRepath (bool autoRepath)

Включает или отключает автоматический пересчёт пути.

Когда autoRepath равно true, агент пересчитывает отклонённый или остановившийся путь.

См. также autoRepath().

void NavMeshAgent::setSpeed (float speed)

Устанавливает максимальную speed движения в мировых единицах в секунду.

Значение speed ограничивает движение мировыми единицами в секунду.

См. также speed().

void NavMeshAgent::setStoppingDistance (float stoppingDistance)

Устанавливает расстояние, при котором агент считает путевую точку достигнутой.

Значение stoppingDistance задаёт расстояние достижения путевой точки в мировых единицах.

См. также stoppingDistance().

float NavMeshAgent::speed () const

Возвращает максимальную скорость движения в мировых единицах в секунду.

См. также setSpeed().

NavMeshAgent::NavigationState NavMeshAgent::state () const

Возвращает текущее состояние навигации.

void NavMeshAgent::stop ()

Останавливает навигацию, очищает текущий путь и сбрасывает скорость агента.

float NavMeshAgent::stoppingDistance () const

Returns the distance at which the agent considers a waypoint reached.

See also setStoppingDistance().

void NavMeshAgent::stuck ()

Emitted when the agent is detected as stuck.

const Vector3 & NavMeshAgent::target () const

Returns the current navigation target.

void NavMeshAgent::unstuck ()

Emitted when a stuck agent starts moving again.

Vector3 NavMeshAgent::velocity () const

Returns the current movement velocity.

void NavMeshAgent::waypointReached ()

Emitted when the agent reaches a waypoint on its current path.
