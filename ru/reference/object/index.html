Object¶

Наследует: None

Описание¶

Object — центральная часть библиотеки Next. Для связи между объектами реализованы два механизма: сигналы и слоты, а также подход на основе событий. Чтобы соединить два объекта, используйте метод connect(), и объект-отправитель будет уведомлять объект-получатель о необходимых событиях.

Объекты можно организовывать в деревья объектов. Каждый объект может иметь неограниченное количество дочерних объектов. Когда вы назначаете родителя объекту, он автоматически добавляет себя в список дочерних объектов родителя. Родительский объект становится владельцем дочернего объекта. Это означает, что дочерний объект будет автоматически удалён при удалении родительского объекта. Дочерний объект можно найти в иерархии объектов по пути или по типу с помощью find(), findChild() или findChildren().

Каждый Object имеет name(), и это имя должно быть уникальным в пределах уровня объекта в иерархии, т.е. родитель с именем «House» не может иметь двух дочерних объектов с именем «Roof». Эти имена используются для доступа к объектам по их путям; land.find(«House/Roof») вернёт объект «Roof».

Каждый Object имеет объявление MetaObject. Систему MetaObject можно использовать для объявления и получения структуры объекта во время выполнения.

На основе модели Actor объект нельзя копировать, только clone().

Описание методов¶

Object::Object ()

Создаёт объект.

По умолчанию Object создаётся без родителя; чтобы назначить родительский объект, используйте setParent().

void Object::addChild (Object * child, int32_t position = -1)

Добавляет child объект во внутренний список дочерних объектов по указанной позиции.

void Object::blockSerialization (bool block)

Если block равно true, объект будет сериализован. Этот флаг будет применён ко всем дочерним объектам в иерархии.

void Object::blockSignals (bool block)

Если block равно true, сигналы, испускаемые этим объектом, будут отброшены (т.е. испускание сигнала не вызовет ничего, что к нему подключено).

Object * Object::clone (Object * parent = nullptr)

Клонирует этот объект. Возвращает указатель на клонированный объект.

Когда вы клонируете Object или его подклассы, все дочерние объекты также будут клонированы. По умолчанию parent для нового объекта будет nullptr. Этот клон не будет иметь уникального имени, поэтому при необходимости его нужно задать вручную.

Предупреждение: Соединения НЕ будут перенесены, и разработчик должен создать их вручную.

См. также connect().

uint32_t Object::clonedFrom () const

Возвращает UUID клонированного объекта.

bool Object::connect (Object * sender, char * signal, Object * receiver, char * method)

Создаёт соединение между signal отправителя и method получателя. Возвращает true в случае успеха; иначе возвращает false.

Вы должны использовать макросы _SIGNAL() и _SLOT() при указании signal и метода.

Примечание: _SIGNAL() и _SLOT() не должны содержать значений параметров, только типы параметров.

class MyObject : public Object {
    A_OBJECT_OVERRIDE(MyObject, Object, Core)

    A_METHODS(
        A_SLOT(onSignal),
        A_SIGNAL(signal)
    )
public:
    void signal(bool value);

    void onSignal(bool value) {
        // Do some actions here
        ...
    }
};
...
MyObject obj1;
MyObject obj2;

Object::connect(&obj1, _SIGNAL(signal(bool)), &obj2, _SLOT(onSignal(bool)));

Примечание: Метод signal в классе MyObject может не иметь реализации. Он используется только в описательных целях в макросах A_SIGNAL(signal).

Сигнал также может быть соединён с другим сигналом.

MyObject obj1;
MyObject obj2;

Object::connect(&obj1, _SIGNAL(signal(bool)), &obj2, _SIGNAL(signal(bool)));

void Object::deleteLater ()

Помечает этот объект для удаления. Этот объект будет удалён, когда цикл событий вызовет метод processEvents() для этого объекта.

void Object::disconnect (Object * sender, char * signal, Object * receiver, char * method)

Отключает signal в объекте sender от method в объекте receiver.

Соединение удаляется, когда любой из объектов уничтожается.

disconnect() можно использовать тремя способами:

Отключить всё от определённого отправителя…

Object::disconnect(&obj1, 0, 0, 0);

Отключить всё, подключённое к определённому сигналу…

Object::disconnect(&obj1, _SIGNAL(signal(bool)), 0, 0);

Отключить все соединения от получателя…

Object::disconnect(&obj1, 0, &obj3, 0);

См. также connect().

TString Object::dynamicPropertyInfo (char * property)

Возвращает дополнительную информацию для динамического свойства.

См. также setDynamicPropertyInfo().

const StringList Object::dynamicPropertyNames () const

Возвращает имена всех свойств, которые были динамически добавлены к объекту с помощью setProperty()

void Object::emitSignal (char * signal, Variant & args = Variant())

Отправляет определённый signal с args всем подключённым получателям.

На данный момент он помещает signal непосредственно в очереди получателей. Если в качестве метода подключён другой signal, этот signal будет испущен немедленно.

Примечание: Получатель должен находиться в цикле событий, чтобы обрабатывать входящее сообщение.

См. также connect().

bool Object::event (Event * event)

Абстрактный обработчик event. Разработчики должны переопределить этот метод для ручной обработки событий. Возвращает true, если event был обработан, иначе возвращает false.

Object * Object::find (TString & path)

Возвращает объект, расположенный по указанному пути.

Object obj1;
Object obj2;

obj1.setName("MainObject");
obj2.setName("TestComponent2");
obj2.setParent(&obj1);

// result will contain pointer to obj2
Object *result = obj1.find("/MainObject/TestComponent2");

Возвращает nullptr, если такого объекта нет.

См. также findChild().

template <typename T> T Object::findChild (bool recursive = true)

Возвращает первого дочернего объекта этого объекта, который может быть приведён к типу T. Поиск выполняется рекурсивно, если только опция recursive не равна false.

Возвращает nullptr, если такого объекта нет.

См. также find() и findChildren().

template <typename T> std::list Object::findChildren (bool recursive = true)

Возвращает всех дочерних объектов этого объекта, которые могут быть приведены к типу T. Поиск выполняется рекурсивно, если только опция recursive не равна false.

Возвращает пустой список, если таких объектов нет.

См. также find() и findChildren().

const Object::ObjectList Object::getChildren () const

Возвращает список дочерних объектов для этог

const Object::LinkList & Object::getReceivers () const

Returns list of links to receivers objects for this object.

bool Object::isSerializable () const

Returns true if the object can be serialized; otherwise returns false.

bool Object::isSignalsBlocked () const

Returns true if emission of signals is blocked; otherwise returns false.

void Object::loadData (VariantList & data)

This method allows to DESERIALIZE data of object like properties, connections and user data.

void Object::loadObjectData (VariantMap & data)

This method allows to DESERIALIZE data. It can be used to DESERIALIZE some specific data like prefabs.

void Object::loadUserData (VariantMap & data)

This method allows to DESERIALIZE data which not present as A_PROPERTY() in object.

void Object::methodCallEvent (MethodCallEvent * event)

Method call event handler. Can be reimplemented to support different logic.

TString Object::name () const

Returns name of the object.

See also setName().

Object * Object::parent () const

Returns a pointer to the parent object.

See also setParent().

void Object::postEvent (Event * event)

Place event to internal event queue to be processed in event loop.

Variant Object::property (char * name) const

Returns the value of the object’s property by name.

If property not found returns invalid Variant. Information of all properties which provided by this object can be found in MetaObject.

See also setProperty() and Variant::isValid().

void Object::removeChild (Object * child)

Removes a child object from the internal list of children.

VariantList Object::saveData () const

This method allows to SERIALIZE all object data like properties connections and user data. Returns serialized data as VariantList.

VariantMap Object::saveUserData () const

This method allows to SERIALIZE data which not present as A_PROPERTY() in object. Returns serialized data as VariantMap.

Object * Object::sender () const

Returns object which sent signal.

Note: This method returns a valid object only in receiver slot otherwise it’s return nullptr

void Object::setDynamicPropertyInfo (char * property, char * info)

Adds additional info for the dynamic property.

Can be used to store meta information mostly used for the editor.

See also dynamicPropertyInfo().

void Object::setName (TString & name)

Set object name by provided name.

See also name().

void Object::setParent (Object * parent, int32_t position = -1, bool force = false)

Makes the object a child of parent at given position.

Note: Please ignore the force flag it will be provided by the default.

See also parent().

void Object::setProperty (char * name, Variant & value)

Sets the property with name to value.

If property not found the object adds dynamic property. Property must be defined as A_PROPERTY(). Information of all properties which provided by this object can be found in MetaObject. An invalid value will bring to deletion of dynamic property.

See also property(), Variant::isValid(), and dynamicPropertyNames().

void Object::setType (TString & type)

Specify an additional type for the object.

Note: Most of the time this method does nothing.

ObjectSystem * Object::system () const

Returns System which handles this object.

TString Object::typeName () const

Returns class name the object.

uint32_t Object::uuid () const

Returns unique ID of the object.
